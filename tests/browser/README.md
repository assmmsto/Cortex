# اختبار المتصفح الحقيقي

اختبارات تفتح Chrome فعلياً وتقيس كل قسم بتدفقه الكامل — لا محاكاة ولا قراءة كود.
كل تأكيد يتحقق من **أثر حقيقي**: عنصر يُرسم، طلب يصل لقاعدة البيانات، عقدة تتحرك.

## الأقسام

| الملف | القسم | ما يقيسه |
|---|---|---|
| `01-notes-graph.cjs` | ① المعرفة · ② الخريطة | عرض المكتبة · فلترة بحث ونوع · فتح عنصر · حفظ يصل لقاعدة البيانات · أزرار السياق · إنشاء عنصر · رسم العُقد والروابط · أشكال حسب النوع · فيزياء حيّة · سحب عقدة · فلتر الخريطة · إخفاء الأسماء |
| `02-sections.cjs` | ⑤ المستودعات · ⑥ المزودون · ⑦ الاستيراد · ⑧ الأدوات | تقنيع المفتاح · رفض عنوان ومفتاح غير صالحين · فهرسة مجلد وجذر المشروع · توزيع الامتدادات · نقاط الدخول · ترابط الكود · أثر التغيير · استيراد ملف فعلي · أدوات MCP |
| `03-team-monitor.cjs` | ③ الوكلاء · ④ المراقبة | وكيل فردي يرد بمصادر · تبويبات اللوحة · فريق متوازٍ يبثّ أحداثه حياً · أثر الأدوات على البطاقات · حكم المراقب وأسبابها · جدول المهام بالأدلة · اختيار تشغيل من القائمة |
| `04-graph-interactive.cjs` | ⑨ الخريطة التفاعلية + نوافذ 2026-10-27 | FileMap (محور/طيّ/تمركز/Esc/أسلاك) · «إضافة مصدر» بأربعة تبويبات · «ربط ذكي» (بحث ⇒ اقتراحات بثقة ⇒ بلا اعتماد) · أقسام المجدول/النبضات/المهارات · ⌘K (مرادفات + تثبيت) — **قراءة فقط** |
| `05-knowledge-agent.cjs` · `06-i18n-audit.cjs` · `07-session-auth.cjs` | ⑤⑥⑦ | لوحة الوكيل · تدقيق اللغة الحقيقي · رمز الجلسة للكتابة |

مداخل بأسماء قياسية (`*.test.cjs`) تُشير إلى الاختبارات نفسها — تُشغَّل يدوياً
و`run.cjs` يستثنيها من الجولة كي لا يُشغَّل القسم مرتين:

| المدخل | يُشير إلى | ملاحظة |
|---|---|---|
| `01-sections.test.cjs` | `01-notes-graph.cjs` | يقلع خادماً معزولاً افتراضياً لأن القسم **يكتب** (يعدّل عنصراً) — خزنة المنتج لا تُلمس |
| `04-interactive.test.cjs` | `04-graph-interactive.cjs` | قراءة فقط — يستهدف الخادم الحي |
| `06-i18n.test.cjs` | `06-i18n-audit.cjs` | قراءة فقط — تدقيق اللغة الكامل |

## التشغيل

```bash
# 1) الخادم في نافذة
npm start

# 2) المتصفح (مرة واحدة)
npm i --no-save playwright-core

# 3) الاختبار
npm run test:browser          # كل الأقسام
node tests/browser/run.cjs 03 # قسم واحد
```

متغيّرات اختيارية:

- `CORTEX_URL` — عنوان الخادم (افتراضي `http://127.0.0.1:3737`)
- `CHROME_PATH` — مسار متصفح غير الافتراضي

الصور تُحفظ في `tests/browser/shots/`.

## لماذا منفصلة عن `npm test`

`npm test` يختبر الوحدات والخادم بلا متصفح (سريع، بلا اعتماديات).
هذه الاختبارات تكشف ما لا يظهر إلا في المتصفح فعلاً — أعطال التخطيط
(`display:none` يجعل SVG صفر الحجم)، وبثّ SSE، وسلوك التخطيط المرئي.
شغّل الاثنين: الوحدات أولاً ثم المتصفح والخادم قائم.

## أدوات الصور

- `node tests/browser/shots.cjs` — صورة لكل قسم (8 صور) في `shots/`
- `node tests/browser/shots-team.cjs` — صورة للفريق **أثناء عمله** (بطاقات حيّة + أثر الأدوات)
  ثم صورة المراقبة بحكمها (3 صور)

هاتان أداتان مساعدتان لا اختباران، فلا يشغّلهما المشغّل تلقائياً.

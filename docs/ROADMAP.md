# Cortex — خارطة الحالة الفعلية (v5 + الواجهة الكربونية + الوكيل)

> هذه الخريطة تصف **ما هو مُنجز ومُختبر فعلًا**، وما تبقّى. لا بنود تخييلية.

## ✅ مُنجز ومُختبر

### المحرك والذاكرة (Layer 1 + 3 + 4)
- خزنة Markdown محلية + frontmatter (أنواع: PRD/Spec/ADR/Meeting/Decision/Note/Procedure/LivingNote)
- استرجاع هجين دائم: معجمي + تضمينات + إعادة ترتيب MMR، مع علامة اتساخ ذكية (لا يعاد بناء الفهرس عبثًا)
- حلّ المراجع الغامضة («افتح المستند») بأسباب معلنة، حالة مساحة مستمرة عبر الجلسات
- صحة المشروع، الفجوات، التناقضات اللفظية، الكيانات، خريطة العقل التفاعلية، الروابط الخلفية، سجل اللقطات القابل للاسترجاع
- نسخ احتياطي ZIP حقيقي بكاتب مدمج (بلا أداة zip)، سجل تدقيق، مزامنة SSE حية

### الطبقة الثانية (Layer 2 — SQLite)
- `cortex-store.js`: مرآة منظّمة (`notes/tasks/links/health_history`) — **استعلامات معاملة فقط**
- مهام بأصحاب ومواعيد (`@owner`, `due:`) + تاريخ صحة زمني لكل مشروع

### الوكيل التنفيذي (Actionable Agent)
- حلقة ReAct (JSON) على أي مزوّد OpenAI-compatible — مُثبت حيًّا على **MiniMax M2.7 عبر Dahl**
- **أدوات (15)**: بحث/قراءة/مهام/حالة/فجوات/**كشف تناقضات**/تلخيص نقدي/استخراج اجتماعات/إنشاء/إلحاق مهام/إلحاق أقسام/ربط/حالة حية/حل مرجع
- **سياسة صارمة**: إضافات فقط — لا حذف ولا كتابة فوق محتوى، وكل إجراء مدقَّق
- توجيه إلزامي للهدف + مسار حتمي احتياطي عند تشتّت النموذج + نبضة تقدّم أثناء الانتظار
- مبادرة: فجوات/تعارضات/عناصر معزولة/قديمة تظهر بشارة عدّ دون سؤال
- **معيار القبول الأصعب مُثبت**: اكتشف تعارض SQLite (PRD) ⇄ IndexedDB (Spec) بمصدرَين وخطورة عالية

### الواجهة (الكربوني — الهوية المعتمدة)
- شريط علوي بتبويبات عرض (تحرير/مزدوج/قراءة/الخارطة/الحالة) + ⌘K + وكيل + MCP + لغة + إعدادات
- عرض الحالة الكامل مع خط الصحة الزمني من SQLite
- **ثنائية اللغة ع↔EN** (اتجاه كامل + قاموس)، **حجم خط S/M/L/XL**، **لون تمييز** — تُحفظ محليًا
- شريط سياق (مهام/مرتبطات/روابط عكسية/سجل)، جداول ماركداون في القراءة، لوحات MCP/الجلسات/الإعدادات
- تربيط مزدوج اللغة للنصوص الديناميكية (t()) + Placeholders + dir=auto للمحتوى

### سطح المكتب (Desktop)
- **Electron v44**: `npm run desktop:native` يفتح نافذة أصلية ويشغّل الخادم إن لزم
- بديل خفيف: `npm run desktop` (Edge/Chrome app-mode)

### الجودة
- 5 ملفات اختبار آلية (API · MCP · استرجاع · SQLite · وكيل) — كلها خضراء
- تحصين: ربط 127.0.0.1 افتراضيًا، CORS محلي، مهلات خارجية، حدّ حجم، 400/413 صحيحة، لا كاش للواجهة

## ⏳ متبقٍ (باتجاهه قرار أو تثبيت خارجي)

1. **تضمينات دلالية حقيقية** — Dahl لا يوفر embeddings (405). يتطلب تثبيت Ollama أو LM Studio + سحب موديل تضمين (غير مثبتين على الجهاز حاليًا)، ثم ضبط مزود الاسترجاع عليه.
2. **تدوير مفتاح Dahl** — ظهر نصيًا أثناء التطوير.
3. **تنقية نهائية للخزنة** — عناصر عرض تجريبية (ثلاثية Atlas + Storage PRD/Spec + Living Notes + ⚠️ ملاحظات المخاطر) جاهزة للتشغيل؛ تُحذف من الواجهة عند الرغبة.
4. **تحسينات اختيارية**: كيانات أدق للعربية (جذور/سوابق)، زمن بث للخطوات في الوكيل، لوحة جلسات أغنى.

# Cortex Product Vision

## Positioning
Cortex is an **operational memory agent**.
It serves engineers, founders, researchers, and autonomous coding environments that need a persistent working brain.

## Problem
Traditional note apps store text. They do not reliably:
- keep project state current
- understand relationships between decisions and tasks
- expose memory safely to model runtimes
- turn working sessions into durable knowledge

## Solution
Cortex provides:
1. local-first memory
2. structured knowledge overlays on top of Markdown
3. MCP-native access for external agents
4. agent workflows for review, synthesis, and execution support

## Entity model
Every knowledge object should evolve toward:
- Note
- Decision
- Task
- Project
- Meeting
- Risk
- Question
- Procedure
- Reference Doc

## Differentiators
- MCP-first rather than plugin-first
- session capture and living notes
- graph + semantic retrieval + project state
- ready to mount into model runtimes

## Primary use cases
- project memory for coding agents
- architecture decision tracking
- sprint memory and execution context
- decision/risk review before shipping
- long-horizon research and synthesis

## Product pillars
### 1. Memory
Local vault, structured metadata, linked knowledge.

### 2. Reasoning
Hybrid retrieval, summarization, review, classification.

### 3. Action
MCP tools, project-state synthesis, runtime integrations.

### 4. Continuity
Session capture, timeline of thought, living notes.

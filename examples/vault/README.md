# examples/vault — بيانات عرض فقط

خزنة تجريبية صغيرة (٦ ملاحظات) مأخوذة من خزنة العرض المتعقَّبة في Git، لتشغيل Cortex
وتجربته دون أي بيانات شخصية. أسماء الملفات هنا هي الجذر الحقيقي للخزنة (لا مجلد فرعي):
الخادم يقرأ `vault/` في جذر المستودع.

| الملف | الغرض |
| --- | --- |
| `a-b-c.md` | ملاحظة عادية بترويسة YAML (`tags`, `importance`, `type`) |
| `hello.md` | أصغر ملاحظة ممكنة — نص فقط بلا ترويسة |
| `untitled.md` | ملاحظة مُنشأة تلقائياً بعنوان افتراضي |
| `rel-alpha.md` | رابط `[[wikilink]]` بين ملاحظتين |
| `atlas.md` | ملاحظة مشروع (`type: project`) بقرار مكتوب |
| `agent-memory.md` | ذاكرة وكيل مولّدة (ملخص إحصاءات الخزنة) |

**للتجربة:** انسخ محتويات هذا المجلد إلى `vault/` في جذر المستودع قبل أول تشغيل،
ثم `npm start`. الخزنة الحقيقية `vault/` غير متعقَّبة في Git ومستثناة من `files`
في `package.json`، فلا تُنشر أبداً.

## الخزنة الفارغة (أول تشغيل)

`cortex-core.js` يُنشئ `vault/` و`data/` عند الإقلاع، و`ensureBaseFiles()` يبذر ثلاث
ملاحظات فقط عندما تكون `vault/` فارغة: `welcome.md` و`ai-roadmap.md` و`mcp-memory.md`.

تحقّقنا عملياً بمجلد مؤقت فارغ: أنتج التشغيل الأول ٣ ملفات و`data/settings.json`،
و`readNotes()` أعاد ٣ ملاحظات، والتشغيل الثاني لم يُنشئ شيئاً (العملية idempotent).
